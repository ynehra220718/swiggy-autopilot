# Swiggy Autopilot

An interactive AI product concept for Swiggy that turns a natural-language meal need into a transparent, ready-to-order cart.

## Prototype

Open `index.html` or visit the repository's GitHub Pages website.

Recommended flow: **Plan my meal → Build carts → Best value → Review cart → Smart swap → Checkout → Save routine**.

## Product case study

The prototype includes the user problem, business opportunity, revenue logic, AI system design, guardrails, MVP scope, experiment plan, success metrics, roadmap, risks, and a 90-second pitch.

`one-pager.html` is a print-ready summary that can be saved as a PDF from the browser.
